# GreenRhythm 2.1.0

В этом выпуске проще найти обновление и разобраться, почему конкретное приложение не работает через VPN.

- Новая плашка над страницами показывает доступную версию. Можно обновиться, скачать пакет с официального сайта, прочитать изменения или отложить предложение до следующего запуска. Кнопка обновления остаётся в боковой колонке.
- На главном экране появилась кнопка «Проверить подписку и Discord». Диагностика сравнивает рабочий профиль с его отдельной проверкой без пользовательских правил и до двух альтернатив из свежей подписки. Подписка не импортируется, подключение не переключается, маршруты не сбрасываются.
- Для Discord отдельно проверяются HTTPS, Gateway WebSocket и контрольный UDP-путь. Пробы повторяются, поэтому отдельные таймауты остаются видны. Эти проверки не подтверждают работу конкретной голосовой сессии и не устанавливают виновника по одной машине.
- Краткий отчёт для поддержки содержит результаты и время проб; ссылки подписок, ключи и названия профилей в него не попадают. Автоматической отправки отчёта нет.
- В настройках видны время последней проверки обновлений и ошибка, если сайт недоступен. После неудачной проверки клиент повторит её через пять минут, без всплывающего окна.
- Повторное нажатие «Обновить» во время проверки или загрузки не запускает вторую операцию. Скачивание сохраняет работу клиента; установка начинается после подтверждения перезапуска. Пакеты проверяются по подписи.
- В окне стандартных маршрутов при отсутствии изменений теперь есть работающая кнопка «Готово». Полный сброс корректно убирает пользовательские значения только после отдельного выбора и подтверждения. При обновлении программы стандартные маршруты автоматически не применяются.

Скачивание для Windows и macOS: [официальный сайт](https://verdantvibe.ru/apps).
