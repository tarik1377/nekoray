# Параметры запуска

- В Windows пользовательские данные по умолчанию хранятся в `%LOCALAPPDATA%\greenrhythm\config`, отдельно от файлов программы. Обновление через приложение доступно и в этом режиме.
- `-appdata [абсолютный путь]` выбирает каталог пользовательских данных; папка `config` создаётся внутри него. Без пути используется стандартный каталог платформы.
- `-portable` в Windows хранит данные в `config` рядом с exe. Тот же режим выбирает файл `portable.flag` рядом с exe. Явный `-appdata` имеет приоритет над файлом; сочетать два параметра нельзя.
- `-many` разрешает несколько экземпляров с одним каталогом данных. Не используйте его для обычной работы и переноса профилей.
- `-tray` запускает приложение в трее.
- `-flag_reorder` переупорядочивает файлы конфигурации и удаляет повреждённые и осиротевшие записи; для обычного обновления не нужен.

Перенос из прежней Windows-копии, ограничения и сохранение автозапуска описаны в [windows-user-data.md](windows-user-data.md). На других платформах режим хранения по умолчанию не меняется.
